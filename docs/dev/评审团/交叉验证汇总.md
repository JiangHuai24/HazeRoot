## 二、单视角发现（待其余评审员返回后合并）

### R3 MT 迁移用户（文件管理专项）

**S 级（会让 MT 用户放弃）：**
1. 长按 = 弹单条菜单，而非进多选（`bindSwipe` L1730 `longFired` 松手走 `fileMenu`）—— 已交叉验证属实
2. 左滑 reveal 区堆「入队/复制/移动/删除」4 按钮，删除红色同级易误触
3. 复制/移动无目标确认，直接 `otherOf(pane)` 后台 cp/mv（L1274/L2387）—— 已交叉验证属实

**A 级：**
4. 双窗无中缝拖调 + 当前窗高亮几乎不可见
5. 无面包屑，只有「上一级+文本框」
6. 长文件名 ellipsize=end 吃掉 .sh 后缀，无看全名兜底
7. APK/压缩包/媒体无类型图标，全落 ic_file

**B 级：** 删除 rm -rf 无回收站、压缩只 tar.gz、解压只认 4 种、重命名无同名检测/后缀保护

### R4 新手易用性（降门槛专项）

**致命：**
1. 首次启动「授权引导」一次性塞进通知权限+Root+ELF+su 术语
2. 未 root 兜底「请确认已刷入 Magisk/KernelSU/APatch」= 死胡同
3. 战略承诺「未 root 三选一引导 FR-11」根本没实现
