## 七、工作规范（务必遵守）

1. **版本号不轻易动**：`commit` 随意、`push` 频繁、**`tag` + 升版本号只在真正发版时**。
2. **commit 用 Conventional Commits**：`feat:` / `fix:` / `refactor:` / `style:` / `docs:` / `chore:`，**不在 message 里写版本号**。
3. **改代码前先读源码确认，不凭猜测**。
4. **每改必编译验证**（`assembleDebug`）。
5. **不擅自改 UI 视觉**——配色/图标/信息架构待用户确认。
6. **不直接复制来源不明的代码**（尤其 GPL 项目）。
